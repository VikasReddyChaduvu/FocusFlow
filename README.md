# FocusFlow

A personal productivity and habit tracking web application to manage daily routines, track habits, set goals, and monitor productivity.

## 🌐 Live Demo

**[Open FocusFlow](https://focusflow-lnan.onrender.com)**

## ✨ Features

- 📊 Productivity dashboard with daily and weekly progress
- ✅ Habit tracking and streak calculation
- 📅 Daily schedule management
- 🎯 Weekly goal tracking
- 💧 Water intake tracking
- 📝 Personal notes and reflections
- 📈 Productivity analytics and charts
- 👤 Customizable user profile
- ⚙️ Light and dark themes
- 💾 Data backup and restore using JSON
- 📱 Responsive design for desktop and mobile

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Tailwind CSS
- Chart.js
- Font Awesome
- LocalStorage API

## 💾 Data Storage

FocusFlow uses browser LocalStorage to save application data locally. Data is not synchronized with a remote server or cloud database.

## 🚀 Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/VikasReddyChaduvu/FocusFlow.git
   ```

2. Open the project folder.
3. Open `index.html` in your browser.
