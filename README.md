# FocusFlow

FocusFlow is a responsive personal productivity and habit tracking web application designed to help users organize their daily routines, track habits, manage study sessions, and monitor their overall progress.

## 🚀 Features

- 📊 Daily productivity dashboard
- ✅ Habit tracking
- 🎯 Daily goals and progress tracking
- ⏱️ Study and focus session tracking
- 💧 Daily water intake tracking
- 📈 Productivity progress visualization
- 📅 Daily routine management
- 💾 Data persistence using browser localStorage
- 📱 Responsive design for desktop and mobile devices
- ⚡ Runs directly in the browser with no backend setup

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6+)
- Tailwind CSS
- Lucide Icons
- Browser LocalStorage
